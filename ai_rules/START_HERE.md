# START_HERE.md

For most unknown or existing projects, begin with:

- `MASTER_SYSTEM.md`
- all files in `core/`
- `modes/REVIEW_MODE.md`
- the best matching file in `tech/`
- all files in `safety/`

If you are unsure which tech rule applies, ask the user.
If no tech rule fits, use `tech/DEFAULT_TECH_RULES.md`.

Do not code before producing:
- task understanding
- chosen mode
- chosen tech rule
- assumptions
- risks
- files likely affected
- plan
- tests or review approach
