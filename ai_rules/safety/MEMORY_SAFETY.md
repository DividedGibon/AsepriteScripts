# MEMORY_SAFETY.md

Do not trust prior conversation or earlier assumptions blindly.

## MEMORY SAFETY RULES

- re-check the current code before changing it
- do not assume earlier steps were correct
- do not assume earlier summaries match the latest files
- verify that referenced files still exist
- verify that architecture understanding still matches the codebase

---

## REPORTING

Clearly distinguish between:

- what is currently observed
- what was previously believed
- what has now been verified
